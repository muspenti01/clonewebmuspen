# Dokumentasi Website Museum Penerangan

Folder ini berisi seluruh dokumentasi teknis dan panduan penggunaan untuk website Museum Penerangan.

## Daftar Dokumen

1.  **[Panduan Admin (PANDUAN_ADMIN.md)](PANDUAN_ADMIN.md)**
    Panduan lengkap untuk administrator dalam mengelola konten website melalui Dashboard Admin.

2.  **[Laporan Konten Statis (LAPORAN_KONTEN_STATIS.md)](LAPORAN_KONTEN_STATIS.md)**
    Daftar bagian-bagian website yang bersifat hardcoded (statis) dan lokasi filenya untuk keperluan editing manual.

3.  **[Laporan Keamanan (LAPORAN_KEAMANAN.md)](LAPORAN_KEAMANAN.md)**
    Laporan mengenai celah keamanan yang ditemukan dan perbaikan yang telah dilakukan.

4.  **[Implementasi Captcha (CAPTCHA_IMPLEMENTATION_GUIDE.md)](CAPTCHA_IMPLEMENTATION_GUIDE.md)**
    Panduan teknis implementasi dan konfigurasi Captcha untuk keamanan form komentar.

5.  **[Remediasi Keamanan (SECURITY-REMEDIATION-CAPTCHA-KOMENTAR.md)](SECURITY-REMEDIATION-CAPTCHA-KOMENTAR.md)**
    Detail langkah perbaikan keamanan khusus untuk isu spam komentar.

Silakan merujuk ke dokumen yang relevan sesuai kebutuhan Anda.
